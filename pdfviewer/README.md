# PDF Viewer

PySide6 + PyMuPDF로 만든 Windows용 PDF 뷰어(읽기 전용). 다크 테마, 탭, 검색, 썸네일·목차·노트 사이드바, 단일·연속·펼침 보기, 발표 모드, 하이라이트·메모·북마크(PDF 는 고치지 않고 따로 저장), AI 채팅.

## 개발 (WSL)

`pdfviewer/` 폴더에서:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # 처음 한 번
.venv/bin/python main.py [파일.pdf ...]                               # 실행 (파일마다 탭 하나)
.venv/bin/pytest -q                                                   # 테스트
```

파일 끌어다 놓기는 WSLg에서 동작하지 않는다. Windows 빌드에서 확인한다.

### WSL에서 겪은 문제 (2026-11-09, Ubuntu 26.04 + WSLg)

**AI 채팅 키.** 키는 코드·git·환경변수에 두지 않는다. 앱의 AI 설정 창(채팅 패널 톱니바퀴)에 넣으면 Windows 는 자격 증명 관리자에, WSL 은 설정 파일(권한 600)에 저장된다. `ANTHROPIC_API_KEY` 환경변수는 읽지 않는다.

```bash
.venv/bin/python main.py 파일.pdf
```

- 경로는 Windows `C:\…` 가 아니라 `/mnt/c/…`, 띄어쓰기가 있으면 따옴표로 감싼다. 실행은 `pdfviewer/` 폴더에서.

**한글 입력.** WSL 앱에는 Windows 한글 입력기가 전달되지 않는다. ibus 를 설치하고, 실행하는 터미널마다 환경변수를 넣는다.

```bash
sudo apt install -y ibus ibus-hangul      # 처음 한 번
export QT_IM_MODULE=ibus XMODIFIERS=@im=ibus GTK_IM_MODULE=ibus
ibus-daemon -drx && ibus engine hangul    # setxkbmap 경고는 무시해도 된다
```

- 앱 안에서 **Shift+Space** 로 한/영 전환 (Windows 한/영 키는 앱까지 오지 않는다. 엔진이 영문 모드로 시작한다).
- 새 터미널에서 `export` 를 빠뜨리면 다시 한글이 안 된다.
- 조합 중 Enter(마지막 글자 빠짐·두 번 전송)는 확인 결과 문제없음.

**목록·메뉴가 닫히지 않음.** 기본(Wayland) 방식으로 켜면 배율 목록 같은 팝업이 항목을 골라도 닫히지 않는다. 시도한 것:

| 실행 방식 | 커서 | 목록 닫힘 |
|---|---|---|
| 기본 (Wayland) | 보임 | 안 닫힘 |
| 한글 설정(ibus) 뺌 | 보임 | 안 닫힘 |
| `QT_WAYLAND_SHELL_INTEGRATION=wl-shell` | 보임 | 안 닫힘 |
| `QT_QPA_PLATFORM=xcb` (X11, 아래 라이브러리 필요) | **안 보임** (`XCURSOR_THEME=Adwaita` 도 효과 없음) | 확인 못 함 |

```bash
sudo apt install -y libxcb-cursor0 libxkbcommon-x11-0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0 libxcb-shape0 libxcb-xkb1
```

- AI 채팅의 범위·모델 고르기는 메뉴 버튼이라 WSLg 에서는 같은 문제가 난다(한때 버튼 세 개였다가 메뉴 버튼으로 돌아옴).
- 코드 문제가 아니다: Phase 9 커밋(`47d1656`)을 그대로 실행해도 똑같이 안 닫힌다. WSLg 환경 문제.
- 목록·메뉴·우클릭 메뉴 동작은 Windows 빌드에서 확인한다.

## Windows 빌드

Windows에 Python 3이 설치돼 있어야 한다(`py` 런처). WSL에서:

```bash
./build_win.sh
```

소스를 `C:\Users\<사용자>\pdfviewer-build\`로 복사하고, 그 안에 Windows용 가상환경을 만들어(처음 한 번) PyInstaller로 빌드한다.
결과는 `C:\Users\<사용자>\pdfviewer-build\dist\PDFViewer\PDFViewer.exe`. `PDFViewer` 폴더 통째로 실행 파일이다(폴더 안의 `_internal`을 지우면 안 된다).
빌드 설정은 `pdfviewer.spec`, 앱 아이콘은 `assets/app_icon.svg`.

## PDF 더블클릭으로 열기 (연결 프로그램)

1. 탐색기에서 PDF 파일을 마우스 오른쪽 클릭 → **연결 프로그램** → **다른 앱 선택**
2. 목록 아래 **PC에서 앱 선택** → `PDFViewer.exe` 선택
3. **항상**을 누른다

다시 빌드해도 경로가 같으므로 등록은 그대로 유지된다. 되돌리려면 **설정 → 앱 → 기본 앱**에서 `.pdf`의 기본 앱을 바꾼다.

## 단축키

앱 안에서 `?` 또는 `F1`(도움말 → 단축키 목록)로도 볼 수 있다. 아래는 기본값이고, 단축키 목록에서 키 칸을 누르고 새 키를 누르면 바로 바뀐다(Esc는 입력 취소, × 지우기, "기본값으로", "전체 초기화"). 다른 기능과 겹친 키는 빨간색으로 표시되고, 겹친 동안은 두 기능 모두 그 키로 동작하지 않는다. Esc·Ctrl+C·메뉴 키(Alt+F 등)는 바꿀 수 없다. 기본값 정의는 `app/shortcuts.py`.

## AI 채팅

오른쪽 패널(Ctrl+Shift+L)에서 지금 페이지·선택한 부분·문서 전체에 대해 묻는다. 답변의 `p.N` 을 누르면 그 페이지로 간다.
답변 아래 "메모로 저장" 을 누르면 답변이 마크다운 기호 없는 글로 질문한 페이지의 **메모**에 들어간다(메모가 있으면 그 아래에 이어 붙임, Ctrl+Z 로 되돌리기). 대화 자체는 저장하지 않는다: 탭을 닫았다 다시 열거나 앱을 다시 켜면 새 대화로 시작한다. 휴지통 버튼은 확인 후 지금 대화를 지운다.
패널 위 톱니바퀴(또는 오류 카드의 "AI 설정 열기")에서 백엔드·키·모델을 바꾼다. 저장하면 다음 질문부터 바로 적용된다(재시작 필요 없음).
질문 칸 왼쪽 아래 모델 버튼(예: "Sonnet 5.5 · 낮음")에서 Claude 모델(Haiku·Sonnet·Opus·Fable, 가격 표시)·AI 설정의 OpenAI 호환 모델과 생각 정도를 바로 고른다.

- **Anthropic**: 키는 이 칸에만 넣는다(환경변수는 읽지 않음). 생각 정도는 낮음이 기본.
- **OpenAI 호환**: 주소·키·모델을 넣는다. 버튼으로 주소를 채울 수 있다(값은 각 제공자 문서로 다시 확인).

| 제공자 | 주소(base_url) | 키 |
|---|---|---|
| Gemini | `https://generativelanguage.googleapis.com/v1beta/openai` | Google AI Studio 에서 무료 발급 |
| Groq | `https://api.groq.com/openai/v1` | 필요 |
| OpenRouter | `https://openrouter.ai/api/v1` | 필요 |
| Ollama (내 PC) | `http://localhost:11434/v1` | 비워 둠 |

모델 이름은 제공자 문서의 이름을 그대로 쓴다. "연결 테스트" 로 저장 전에 확인한다. OpenAI 호환 쪽은 프롬프트 캐싱·토큰 표시가 제공자마다 다르다.

## 하이라이트·메모·북마크

글자를 드래그하면 바로 아래에 막대가 뜬다: 복사 · AI에게 질문 · 색 4개. 색을 누르면 하이라이트.
하이라이트를 누르면 색 바꾸기 · 코멘트(Ctrl+Enter 저장, Esc 취소) · AI에게 질문 · 삭제. 지금 색을 다시 누르면 하이라이트가 지워진다(하이라이트된 글자를 다시 드래그해 같은 색을 눌러도 같음, Ctrl+Z 로 되돌리기). 코멘트는 하이라이트에 마우스를 올리면 보인다. 마지막으로 고른 색이 `H` 의 색이 된다.

`M` 은 지금 페이지의 메모(페이지당 1개, 비우고 저장하면 지워짐), `B` 는 북마크. 페이지 오른쪽 위에 노란 리본(메모)과 초록 리본(북마크)이 보이고(화면보다 큰 페이지에서는 화면 오른쪽 위에 따라 붙음), 메모 표시를 누르면 고친다. 북마크 리본은 눌러도 지워지지 않고 `B` 나 메뉴로 끈다. `]` / `[` 로 다음·이전 북마크로 가고, 노트 탭의 북마크에는 그 페이지 첫 줄이 이름으로 붙는다. 우클릭 메뉴와 도구 모음(메모 · 북마크 · 되돌리기 · 다시 실행 아이콘)에도 있다.
사이드바 **노트** 탭(Ctrl+Shift+N): 하이라이트/메모/북마크 중 하나를 골라 페이지 순으로 본다. 항목을 누르면 그 위치로 가고, 우클릭으로 편집·삭제·AI에게 질문. 상태바에 저장 상태(저장 중… / 저장됨 / 저장 실패)가 보인다.

파일 메뉴 **노트를 클립보드로 복사** 는 북마크 · 페이지별 하이라이트(인용 + 코멘트)와 메모를 마크다운으로 복사한다(노션·문서에 붙여넣기용). 노트는 앱이 따로 저장하니 PDF를 다시 열면 그대로 보인다.

PDF 파일은 고치지 않는다. 하이라이트는 문서마다 따로 저장되고, 파일 **내용** 으로 찾으므로 PDF 를 옮기거나 이름을 바꿔도 그대로 나온다(내용이 바뀐 PDF 는 다른 문서로 본다).

- 저장 위치: Windows `%APPDATA%\pdfviewer\pdfviewer\notes\`, WSL `~/.local/share/pdfviewer/pdfviewer/notes/`. 백업은 이 폴더를 복사하면 된다.
- 깨진 노트 파일은 `.json.bak` 으로 옮겨 두고 새로 시작한다(상태바에 안내).

## 설정과 로그

- 설정(창 크기, 최근 파일, 파일별 페이지·확대, 바꾼 단축키, AI 설정): Windows 레지스트리 `HKCU\Software\pdfviewer\pdfviewer`. AI 설정 창에 넣은 API 키는 여기가 아니라 **Windows 자격 증명 관리자**(일반 자격 증명 `pdfviewer`)에 저장된다. WSL 처럼 암호 저장소가 없는 곳에서는 설정 파일(`~/.config/pdfviewer/pdfviewer.conf`)에 그대로 두고 파일 권한을 600 으로.
- 로그: `%APPDATA%\pdfviewer\pdfviewer\pdfviewer.log` (1MB씩 최대 3개). 오류가 나면 이 파일을 확인한다.

### Phase 11a 변경사항
- 새 파일
  - `app/core/annotations/store.py`: 문서별 메모 JSON. 내용 해시로 문서를 찾고, 임시 파일 → 바꿔치기로 저장한다. 깨진 파일은 `.bak` 으로 옮기고, 새 버전 파일은 덮어쓰지 않는다.
  - `app/annotation_state.py`: 메모 상태 담당. 내용 해시는 백그라운드에서 계산하고, 문서별 되돌리기 기록을 따로 둔다. 0.5초 모아서 저장한다.
- 바뀐 파일
  - `page_view.py`: 하이라이트 그리기, 하이라이트 클릭, 드래그 후 막대(창 안 위젯), 코멘트 칸·툴팁.
  - `main_window.py`, `shortcuts.py`: 하이라이트(H)·실행 취소·다시 실행 메뉴와 단축키, 종료 때 저장, 상태바 경고.
  - `settings.py`: 파일별 내용 해시 캐시, 마지막 하이라이트 색.
  - `tokens.json`, `base.qss`: 하이라이트 색 4개·투명도, 막대 스타일.

- 코멘트·쪽 메모 입력창을 옮기고 키울 수 있게(사용자 요청). 입력창 빈 곳(저장 버튼 왼쪽·테두리)을 끌면 이동, 오른쪽 아래 모서리를 끌면 크기 조절. 옮긴 창은 스크롤해도 그 자리에 있고, 하이라이트가 화면 밖으로 나가면 전처럼 저장하고 닫힘. 키운 크기는 설정에 저장해 앱을 다시 켜도 다음 메모가 그 크기로 열림(사용자 요청). 크기는 모서리에서 손을 뗄 때 바로 저장(메모창을 연 채 앱을 꺼도 유지).
- 메모 탭의 문서 노트 제거(사용자 요청). 아래 줄은 내보내기 | 개수 두 칸. 예전에 써 둔 문서 노트는 메모 파일에 그대로 남고 내보내기에도 그대로 나옴(데이터는 지우지 않음).
- 묶음 이름 "메모" → "노트"(사용자 요청, 항목 이름 "메모"와 헷갈려서): 사이드바 노트 탭, 파일 메뉴 노트 내보내기…·노트를 클립보드로 복사, 저장·내보내기 안내 문구, 내보낸 파일의 제목 없을 때 기본 제목. 필터의 "메모", "쪽 메모", "AI 메모", 채팅의 "메모로 저장" 은 항목 이름이라 그대로.
- 하이라이트를 눌러 나온 막대에서 지금 색 동그라미를 다시 누르면 하이라이트 지우기(사용자 요청, Ctrl+Z 로 되돌리기). 다른 색은 전처럼 색 바꾸기. 지금 색의 툴팁은 "노랑 하이라이트 지우기" 처럼 바뀜.
- 이미 하이라이트된 글자를 다시 드래그해 같은 색을 누르면 같은 하이라이트가 하나 더 생기던 것 → 지우기로(사용자 제보). 선택한 글자를 다 덮는 하이라이트가 있으면 그 색 동그라미가 표시되고 누르면 그 하이라이트를 지움(일부만 골라도 하이라이트 전체). H 키도 같음.
- 노트 파일 내보내기(Ctrl+E, 파일 메뉴 "노트 내보내기…")와 노트 탭 아래 "내보내기" 버튼 제거(사용자 요청: 노트는 앱이 저장하고 다시 열면 보임). 앱 밖으로 꺼낼 때는 파일 메뉴 "노트를 클립보드로 복사". 노트 탭 아래 줄은 개수만.
- AI 채팅 위의 검정 칸 없앰(사용자 요청): 창 사이 틈·채팅 바깥 바탕을 bg_base → bg_panel(탭 줄·도구 모음·상태바와 같은 색). 문서 영역만 더 어두운 색. 채팅 위쪽 줄 설정 오른쪽에 닫기(X) 버튼.
- 사이드바를 닫으면 문서 영역도 창 왼쪽 끝에서 8px 띄움(사용자 요청, 사이드바가 있을 때와 같은 틈, 바탕은 문서 쪽과 같은 어두운 색 `QWidget#central`). 발표 모드는 그대로 끝까지.
- AI 채팅 모델 버튼(사용자 요청): 질문 칸 아래 왼쪽, 범위 버튼과 같은 모양. 메뉴는 모델(Claude 4개 + AI 설정에 넣은 OpenAI 호환 모델) · 생각 정도(Claude 만) · AI 설정…. 고르면 바로 저장·적용(`chat_state.update_config`). 모델 이름은 버튼에 있으니 채팅 위 정보 줄에서는 뺌. Fable 5.2 도 거절 시 대체 모델(fallback) 목록에 넣음.
- 보안 정리(사용자 요청, 앞선 점검 결과):
  - AI 답변·AI 메모의 마크다운 이미지(`file:///…`, `//서버/공유/…`)를 불러오지 않음(`notes_model.TextOnly`: 빈 1×1 그림). Windows 에서 공유 폴더 주소를 열면 로그인 해시가 그 서버로 가기 때문. 위젯의 loadResource 만 막으면 Qt 가 파일을 직접 읽어서 문서 쪽에서 막음(테스트로 확인).
  - PDF 속성 창의 제목·저자 등, AI 설정의 연결 테스트 결과, 메모·코멘트 툴팁은 HTML 로 해석하지 않고 글자 그대로.
  - API 키는 Windows 자격 증명 관리자에(`keyring`, requirements 추가). 예전 버전이 설정에 평문으로 둔 키는 처음 읽을 때 옮기고 설정에서 지움. 저장소가 잠겨 실패하면 키를 잃지 않게 설정에 남김. WSL 은 저장소가 없어 설정 파일 권한만 600.
  - OpenAI 호환 주소가 `http://` 인데 localhost 가 아니면 키를 보내지 않고 오류 카드("https:// 로 바꾸세요").
  - 답변 속 `page:abc` 같은 이상한 링크를 눌러도 멈추지 않음.
  - `ANTHROPIC_API_KEY` 환경변수를 더 이상 읽지 않음(사용자 요청): 키는 AI 설정 창 한 곳에서만. 안내 문구·오류 힌트에서도 환경변수 언급 제거.
  - 테스트 206개.
- AI 답변 저장 방식 변경(사용자 요청): "메모로 저장" 은 따로 된 AI 메모가 아니라 그 페이지의 일반 메모에 이어 붙임(글자만, 노란 리본, 편집 가능). 대화 기록 저장·복원 기능과 AI 설정의 "대화 기록 저장" 체크 제거(질문마다 지난 대화를 다시 보내 비용이 늘고 답이 흐려져서). 예전에 저장된 AI 메모·대화 기록 데이터는 노트 파일에 그대로 남음(AI 메모는 전처럼 목록에 보임, 대화 기록은 읽지 않음).
- 탭을 닫았다 같은 실행 안에서 다시 열면 전 대화가 나오던 것(사용자 제보: 메모리에 남아 있었음) → 탭을 닫으면 그 파일의 대화도 버림(`chat_state._forget_closed`).
- 오류 창 "문제가 생겼어요"(사용자 제보, 로그: QWidgetAction already deleted): 도구 모음의 확대 묶음 맞춤이 예약된 채 창이 닫히며 도구 모음 부품이 먼저 지워진 경우 → 지워졌으면 건너뜀(`toolbar.align_zoom`, `main_window._align_toolbar`). 같은 상황을 만드는 테스트 추가(207개).
