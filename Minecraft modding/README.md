# Harbor Trade

중세 항구도시를 배경으로 한 마인크래프트 멀티플레이 경제 게임 모드입니다.

## 프로젝트 목표

- **장르:** 중세시대 경제 게임 (멀티플레이)
- **맵:** 항구도시
- **승리 조건:** 돈을 벌어 특정 아이템(승리 아이템)을 가장 먼저 목표 개수만큼 구매하면 승리
- **배포:** Modrinth 모드팩(.mrpack) — 모드 + 의존 모드 + 항구 맵 + 설정 포함

### 기술 기반

| 항목 | 결정 |
|---|---|
| 모드 로더 | Fabric |
| 마인크래프트 버전 | 1.21.1 |
| 설치 방식 | 서버 + 클라이언트 모두 설치 (전용 UI/HUD/NPC 사용) |
| 개발 환경 | Java 21 (모드 대상), Java 25 (빌드 도구 Loom 실행용) |

### 구현할 시스템

1. 핵심: 화폐 · NPC 상점/동적 가격 · 승리 조건 · 라운드 관리
2. 항구 콘텐츠: 무역/항로 · 직업/생산 · 부동산 · 이벤트 · 금융(선택)
3. 운영: UI · NPC · 맵 · 관리자 명령어 · 설정 파일 · 악용 방지

## 개발 방법

- 빌드: `./gradlew build` (결과물: `build/libs/`)
- 클라이언트 실행: `./gradlew runClient`
- 서버 실행: `./gradlew runServer`

## 진행 상황

### 2026-09-29

**기술 기반 결정 및 프로젝트 뼈대**
- Fabric 1.21.1 / 서버+클라이언트 설치 / 모드팩 배포로 결정
- Fabric 공식 예제를 바탕으로 프로젝트 생성 (모드 ID `harbortrade`, 패키지 `com.seunghyeon.harbortrade`)

**화폐 시스템 (1단계)**
- 동전 아이템 3종: 동화(1) · 은화(100) · 금화(10,000). 모든 금액은 동화 기준 정수로 계산
- 플레이어별 은행 잔액을 월드 데이터에 저장
- 한국어 명령어

  | 명령어 | 기능 |
  |---|---|
  | `/돈` | 은행 잔액 · 보유 현금 보기 |
  | `/돈 입금 [금액]` | 현금 입금 (금액 생략 시 전액, 거스름돈은 동전으로 반환) |
  | `/돈 출금 <금액>` | 은행 → 동전 |
  | `/돈 송금 <플레이어> <금액>` | 계좌 송금, 보내는 사람이 수수료 10% 추가 부담 (올림, 수수료는 소멸) |
  | `/돈 관리 설정/지급 <플레이어> <금액>` | 관리자 전용 |

- 시작 자금 없음
- 사망 시 동전을 떨어뜨리지 않고 부활할 때 돌려받음
- 검증: 빌드 성공, 테스트 서버 정상 실행, `/돈` 명령어 등록 확인
- 미검증 (플레이어 접속 필요): 입금·출금·송금 동작, 사망 시 동전 유지, 동전 텍스처 표시
