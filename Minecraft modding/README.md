# Harbor Trade

중세 항구도시를 배경으로 한 마인크래프트 멀티플레이 경제 게임 모드입니다.

## 프로젝트 목표

- **장르:** 중세시대 경제 게임 (멀티플레이)
- **맵:** 항구도시
- **승리 조건:** 돈으로 명성상점에서 명성을 구매해, 게임이 끝났을 때 **명성이 가장 높은 사람**이 우승
- **배포:** Modrinth 모드팩(.mrpack) — 모드 + 의존 모드 + 항구 맵 + 설정 포함

### 기술 기반

| 항목 | 결정 |
|---|---|
| 모드 로더 | Fabric |
| 마인크래프트 버전 | 1.21.1 |
| 설치 방식 | 서버 + 클라이언트 모두 설치 (전용 UI/HUD/NPC 사용) |
| 개발 환경 | Java 21 (모드 대상), Java 25 (빌드 도구 Loom 실행용) |

## 게임 설계

### 진행 방식

- **회차제:** 1회차 = 현실 시간 3시간. 관리자가 회차를 시작하고, 회차가 끝나면 서버를 닫았다가 다 같이 모일 때 다시 연다.
- **초기화 없음:** 잔액 · 보석 · 인벤토리 · 땅 · 보석 시세가 모두 다음 회차로 이어진다. 게임 전체 종료 시점은 관리자가 정한다.
- **회차 타임라인:**

  | 경과 시간 | 이벤트 |
  |---|---|
  | 0:00 | 회차 시작, "오늘의 무역상품" 카테고리 공개 |
  | 0:30 | 보석상 개장 |
  | 1:00 · 1:30 · 2:00 · 2:30 | 보석 시세 변동 (2:30이 마지막) |
  | 1:30 | 무역상 도착 — 오늘의 무역상품을 외부 도시로 판매(선적) 가능 |
  | 1:40 | 무역상 출항 |
  | 1:45 | 도시별 결과 발표: +20% ~ -5% 수익 또는 손해 |
  | 3:00 | 회차 종료, 보석상 폐장 (다음 회차 0:30까지 보석 거래 불가), 명성 순위 발표 |

- 예고 공지는 하지 않는다.

### 경제

- **화폐:** KD (원화와 같은 개념, 1,000원 = 1,000 KD). 실물 화폐는 없고 **모든 돈은 은행 계좌**에만 있다. 송금 기능 없음.
- **보석:** 플레이어 사이의 **유일한 거래 수단**. 보석상에서 사서 직접 건네주고, 받은 사람이 보석상에 판다.
  - 6종: 자수정 100 · 토파즈 1,000 · 진주 5,000 · 사파이어 20,000 · 루비 100,000 · 금강석 1,000,000 KD (기준가)
  - 시세 변동: 회차 타임라인에 따라 보석별로 최대 ±15%, 정수로 반올림, 기준가의 50~200% 범위
  - 보석상은 현재 시세 그대로 사고판다 (차액 없음)
  - 죽으면 떨어뜨린다 (바닐라 규칙)
- **일반 상점:** 식료품상 · 대장장이 · 어부. **판매 전용**(플레이어가 팔기만 함, 상점은 물건을 팔지 않음) — 돈은 직접 생산한 물건으로만 번다. 가격은 고정.
- **무역상:** 회차마다 무작위로 정해지는 "오늘의 무역상품" 카테고리만 외부 도시로 팔 수 있다. 세부 방식은 설계 중.
- **명성상점:** 명성을 고정가로 판매. 명성은 계좌처럼 저장되는 점수이며 남에게 줄 수 없다. 회차 내내 영업하고, 순위는 회차 종료 때 발표. 동점이면 먼저 달성한 사람이 이긴다.
- **초반 지원금:** 지급한다. 금액은 물가가 정해진 뒤 확정.
- **추가 수익 수단:** 별도로 마련 예정.

### 미정 사항

- 모든 가격 (지원금, 명성 가격, 상품 판매가, 무역가)
- 무역상 세부 방식 (외부 도시 구성, 카테고리별 품목, 기준가)
- 추가 수익 수단

## 명령어

| 명령어 | 권한 | 기능 |
|---|---|---|
| `/돈` | 모두 | 은행 잔액 보기 |
| `/가격` | 모두 | 보석 시세 보기 |
| `/회차` | 모두 | 현재 회차, 경과 시간, 다음 이벤트, 오늘의 무역상품 |
| `/돈 관리 설정 <플레이어> <금액>` | 관리자 | 잔액 지정 |
| `/돈 관리 지급 <플레이어> <금액>` | 관리자 | 돈 지급 |
| `/가격 관리 변동` | 관리자 | 보석 시세 즉시 변동 (테스트용) |
| `/상점 설치 식료품상\|대장장이\|어부\|보석상` | 관리자 | 내 위치에 상인 NPC 설치 |
| `/상점 제거` | 관리자 | 4칸 안의 가장 가까운 상인 제거 |
| `/상점 새로고침` | 관리자 | `config/harbortrade/shops.json` 다시 읽기 |
| `/회차 시작` · `/회차 종료` | 관리자 | 다음 회차 시작 · 현재 회차 강제 종료 |
| `/회차 일시정지` · `/회차 재개` | 관리자 | 회차 시간 멈춤 · 다시 흐르게 함 |
| `/회차 건너뛰기 <분>` | 관리자 | 회차 시간 앞당기기 (테스트용) |

관리자 권한은 서버 콘솔에서 `op <닉네임>`으로 준다.

## 개발 방법

- 빌드: `./gradlew build` (결과물: `build/libs/`)
- 클라이언트 실행: `./gradlew runClient`
- 서버 실행: `./gradlew runServer`
- 모드팩 만들기: `./gradlew build` 후 `python3 modpack/build_mrpack.py` (결과물: `build/harbortrade-<버전>.mrpack`)

## 모드팩

`modpack/mods.json`에 적힌 모드와 그 모드들이 필요로 하는 모드(자동 포함), 그리고 Harbor Trade를 묶어 Modrinth 모드팩(.mrpack)을 만듭니다. 모드를 추가하거나 빼려면 `modpack/mods.json`만 고치면 됩니다.

### Modrinth 앱에서 실행하기

1. Windows에 Modrinth App 설치 (modrinth.com/app)
2. 앱에서 인스턴스 추가(+) → **파일에서 가져오기** → `harbortrade-<버전>.mrpack` 선택
3. 생성된 인스턴스를 실행하고, 싱글플레이 월드(치트 허용)로 테스트하거나 서버에 접속

> WSL 안에서 `./gradlew runClient`로 실행하면 그래픽카드를 제대로 쓰지 못해 매우 느립니다. 게임 테스트는 Windows의 Modrinth 앱으로 하세요.

### 포함된 모드

| 모드 | 역할 | 설치 위치 |
|---|---|---|
| Harbor Trade | 이 프로젝트 (화폐 · 보석 · NPC 상점 · 회차) | 서버 + 클라이언트 |
| Fabric API | 필수. Fabric 모드들이 쓰는 기본 라이브러리 | 서버 + 클라이언트 |
| Open Parties and Claims | 토지 보호와 파티 (부동산 시스템 기반) | 서버 + 클라이언트 |
| Forge Config API Port | Open Parties and Claims가 필요로 하는 설정 라이브러리 (자동 포함) | 서버 + 클라이언트 |
| Simple Voice Chat | 가까이 있는 플레이어끼리 음성 채팅 | 서버 + 클라이언트 |
| Sodium | 성능: 렌더링 최적화 (프레임 향상 효과가 가장 큼) | 클라이언트 |
| ImmediatelyFast | 성능: UI·글자 렌더링 최적화 | 클라이언트 |
| Entity Culling | 성능: 벽 뒤 등 안 보이는 엔티티를 그리지 않음 | 클라이언트 |
| Lithium | 성능: 게임 로직(몹, 블록 갱신 등) 최적화 | 서버 + 클라이언트 |
| FerriteCore | 성능: 메모리 사용량 감소 | 서버 + 클라이언트 |
| ModernFix | 성능: 로딩 속도·메모리 개선 | 서버 + 클라이언트 |
| Krypton | 성능: 서버 네트워크 최적화 | 서버 |

`modpack/mods.json`에서 `"side"`로 설치 위치를 정합니다: `"client"`는 Modrinth 앱(플레이어)에만, `"server"`는 서버에만 설치되고, 생략하면 양쪽 모두 설치됩니다.

### 성능 모드 사용법

성능 모드는 **설치만 하면 자동으로 동작**하며 따로 조작할 것이 없습니다.

- **Sodium:** 비디오 설정 화면이 Sodium 전용 화면으로 바뀝니다. 렉이 있으면 `설정 → 비디오 설정`에서 렌더 거리를 낮추세요.
- **나머지(ImmediatelyFast, Entity Culling, Lithium, FerriteCore, ModernFix, Krypton):** 설정 없이 기본값으로 사용합니다. 문제가 생기면 해당 모드를 `modpack/mods.json`에서 빼고 모드팩을 다시 만들어 원인을 확인합니다.
- **Krypton**은 서버 전용이라 Modrinth 앱(싱글플레이) 인스턴스에는 설치되지 않습니다.

### Open Parties and Claims 사용법

청크(16×16 칸) 단위로 땅을 "소유"해서 다른 플레이어가 부수거나 상자를 열지 못하게 막는 모드입니다. 파티를 만들면 파티원끼리는 서로의 땅을 쓸 수 있습니다.

- **메뉴 열기:** 게임 안에서 `'` 키(작은따옴표)를 누르면 메인 메뉴가 열립니다.
- **땅 소유하기:** 메뉴의 청크 소유(Claims) 지도 화면에서 원하는 청크를 선택해 소유합니다. 명령어 `/openpac-claims`로도 할 수 있습니다(Tab 키로 하위 명령 자동완성).
- **파티:** 메뉴의 파티(Party) 화면이나 `/openpac-parties` 명령어로 파티를 만들고 다른 플레이어를 초대합니다.
- **서버 설정:** 1인당 소유 가능한 청크 수 등은 월드 폴더의 `serverconfig/openpartiesandclaims-server.toml`에서 조정합니다.
- 항구도시의 공용 구역(시장, 항구)은 관리자가 서버 소유로 보호해 두고, 나중에 부동산 시스템에서 플레이어에게 판매·임대할 예정입니다.

### Simple Voice Chat 사용법

가까이 있는 플레이어의 목소리만 들리는 근거리 음성 채팅입니다. 멀어질수록 소리가 작아집니다.

- **처음 실행:** 게임에 들어가면 마이크 설정 안내가 나옵니다. `V` 키로 음성 채팅 설정 화면을 열어 마이크와 스피커를 고릅니다.
- **말하기:** 기본은 **누르고 말하기**이고, 키는 `Caps Lock`입니다. 설정 화면에서 음성 감지(자동)로 바꿀 수 있습니다.
- **그룹 채팅:** `G` 키로 그룹을 만들면 거리와 상관없이 그룹원끼리 대화할 수 있습니다.
- **서버를 열 때:** 음성은 게임과 별도로 **UDP 24454 포트**를 씁니다. 서버 방화벽이나 공유기에서 이 포트를 열어야 합니다. 설정은 `config/voicechat/voicechat-server.properties`에서 합니다(들리는 거리 `max_voice_distance` 등).
